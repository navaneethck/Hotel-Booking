# Hotel Booking Application

A full-stack hotel booking application built with the MERN stack. The application allows users to search hotels, check room availability, book rooms, and complete payments using Razorpay (test mode). Images are managed through Cloudinary, and user authentication is handled with JWT.

## Live Demo

https://hotel-booking-ebon-three.vercel.app/

## Features

* User Authentication
* Hotel Search
* Hotel Filtering
* Room Availability Check
* Hotel Booking
* Guest Details
* Razorpay Payment Integration (Test Mode)
* Cloudinary Image Upload
* Responsive Design
